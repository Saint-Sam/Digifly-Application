# Digifly Workstation 0.2.1

The installed version now appears at the bottom left of every app page. The
label reads the build information included with the app, fixing the outdated
version shown in the sidebar. It stays visible when switching pages, resizing
the window or showing temporary status messages.

Downloads are available for Apple Silicon Macs and 64-bit Windows. Windows
includes the NEURON installer. Existing projects, neuron libraries, simulator
installations and recordings are preserved during updates.

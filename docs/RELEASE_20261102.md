This alpha adds a first-experiment tutorial for Male CNS v1.0. It follows a
16-neuron circuit containing DNp01, TTMn, PSI and DLMn through download, skeleton
repair, circuit settings, a NEURON experiment and recorded results.

## First experiment

- Previous and Next guide each step. The app dims the background and leaves the
  controls needed for that step accessible.
- The tutorial can be paused and resumed. Downloads, repairs and simulations
  still use the app's normal buttons and confirmation dialogs.
- Each step shows its instructions and bottom navigation. The repeated details
  and action panel has been removed; required values appear in the instructions.
- Larger contact files are checked incrementally, without the earlier fixed
  file-size cutoff.

## Repairs and recordings

Data Library connectome pictures now use the screen's pixel density, keeping
their detail on Retina and Windows-scaled displays.

Radius-repaired and joined skeleton copies now stay indexed and selectable.
The app checks their connection to the original files, including copies that
went through both repairs. Original geometry and contact locations are preserved.

Both downloads include sparse and full-compartment current recording, shared
loading for replay and traces, and a checked lossless cache for reopening large
recordings. Progress and cancellation are available during loading. Trace search
and paging keep the full recording accessible.

## Installation

Choose the macOS Apple silicon or Windows x86-64 ZIP under Assets. Both are
build 20261102.8. Extract the ZIP before opening the app.

Mac requires macOS 14 or later. The app is ad-hoc signed; use right-click and
Open if macOS blocks it. Windows is unsigned and includes NEURON 9.0.2 with an
offline, per-user setup option. Projects, SWCs, simulator installations and
recordings stay outside the application.

Some older updaters require a one-time manual download.

## Known issues

The short 16-neuron teaching experiment completed with recorded voltage changes
and no spikes. Students can inspect those measurements in replay and traces.

Windows package checks run on Windows Server 2022. Windows 11 and a clean-Mac
NEURON installation still need testing. The broader student-control review is
unfinished. Large result loads can briefly pause, a cancelled load can leave a
stale heading, and some exported legends or axis labels need layout work.

See the repository's bug and fix log for individual repairs and remaining checks.

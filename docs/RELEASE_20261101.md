This alpha updates both app downloads: macOS 20261031.14 and Windows 20261026.9.

## Circuit experiments

- Run connected circuits using downloaded chemical contact locations, or an editable connection model when only pair counts are available.
- Keep skeleton repairs as separate copies while preserving original points and contact locations. An optional axon-aware bridge uses nearby intact axon diameters.
- Record voltage across compartments and review measured signal propagation beside traces. Experiment settings are checked before a run starts.

## Newer Mac changes

Mac adds sparse or full-compartment current recording and faster loading of large saved recordings. A checked, lossless cache lets replay and traces share the recorded samples. Loading has progress and cancellation; every saved trace remains accessible through search and paging.

In the 50-neuron test, opening 57.95 million voltage samples took 149 seconds initially, 1.1 seconds when reopening, and 9.7 seconds after restarting the app. The saved data was unchanged.

Windows 20261026.9 includes the connected-circuit and skeleton-repair work above. The newer Mac current-tracking controls and loading repair have not yet been brought into this Windows package.

## Installation

Choose the macOS Apple silicon or Windows x86-64 ZIP under Assets. Mac requires macOS 14 or later. It is ad-hoc signed; right-click the extracted app and choose Open if macOS blocks it. Windows is unsigned: use Extract All before opening the executable. Its download includes NEURON 9.0.2 and an offline, per-user setup option.

Projects, SWCs, simulator installations and run results stay outside the app. Some older app versions need a one-time manual download because their updater expects the discontinued checksum files.

## Known issues

Mac can still pause briefly during a large load; the longest gap in the fresh-start test was 0.64 seconds. Cancelled loading can leave a stale heading. Long export legends may clip, and one voltage-axis label can overlap a tick.

Testing every student-facing control is ongoing. Windows package checks ran on Windows Server 2022; Windows 11 testing is incomplete. Simulation results depend on the chosen cell models, connection strengths and placement assumptions.

# Digifly mark

The paired blue and cyan traces are an original Digifly application mark,
created for this repository in 2026. Its silhouette is a deliberately
simplified visual interpretation of the bilateral Drosophila giant fibers,
including their long descending shafts and characteristic terminal bends. It
is not a cropped or recolored connectome rendering.

The PNG is the editable high-resolution source used by the application. The
ICNS file is a multi-resolution macOS derivative. Both are covered by the
repository's private development license.

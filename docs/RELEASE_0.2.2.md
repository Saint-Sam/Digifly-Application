# Digifly Workstation 0.2.2

Neuron names now work consistently in Experiment Builder. Recording and
comparison ablations accept exact types and saved aliases, alongside numeric
IDs. Entering TTMn selects every TTMn in the loaded circuit.

The same selections carry through readiness checks, saved projects and simulator
requests. Missing names identify the affected field, and refreshed neuron labels
appear without changing the loaded geometry. Commas, semicolons and whitespace
are accepted between targets.

Mac and Windows downloads are included. Existing neuron libraries, simulator
installations and recordings are preserved during updates.
